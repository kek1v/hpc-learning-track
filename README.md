# HPC Track

Русскоязычный учебный трек по высокопроизводительным вычислениям (HPC) и системному программированию. Подходит тем, кто начинает изучать C++ или возвращается к нему после перерыва. Маршрут начинается с небольшой программы и заканчивается проектом, в котором нужно распределить вычисление скалярного произведения между процессами MPI и потоками OpenMP, проверить результат и измерить ускорение.

## Что внутри

- **91 урок в девяти модулях.** В C++ — 19 уроков, включая сборку с CMake, тесты через CTest и отладку с GDB. Ещё по девять уроков посвящены Linux, Git, многопоточности, OpenMP, MPI, оптимизации памяти, SIMD и профилированию.
- **Ежедневная практика.** План на день объединяет урок, упражнение и самопроверку. Можно записать ожидаемый результат, выполнить пример в своём терминале и сохранить наблюдения рядом с кодом.
- **Закрепление материала.** Пройденные уроки попадают в очередь интервального повторения. Журнал ошибок и тесты по модулям возвращают в эту очередь темы, с которыми возникли трудности.
- **Подготовка к отклику.** Приложение загружает удалённые позиции Canonical через Greenhouse, отмечает совпадения с личным чек-листом навыков и отделяет открытые вакансии от новых. При недоступности источника показывает сохранённую подборку с датой проверки.

## Локальный запуск

Потребуется Python 3. Из корня репозитория запустите статический сервер.

```sh
python -m http.server 8000 --bind 127.0.0.1 --directory dist
```

В Windows с Python Launcher можно использовать `py -3` вместо `python`, в Linux и macOS — `python3`. Затем откройте [учебный центр](http://127.0.0.1:8000). Сервер останавливается сочетанием `Ctrl+C`.

## Устройство приложения

Интерфейс написан на HTML, CSS и JavaScript. Каталог `dist/` содержит готовый сайт и подходит для статического хостинга. Учебные материалы находятся в `course.js`, `cpp-more.js`, `systems-more.js` и `hpc-more.js`. Вопросы модульных тестов находятся в `checks.js`, логика занятий — в `app.js`, загрузка вакансий — в `jobs.js`.

Прогресс, заметки, журнал и история вакансий сохраняются в `localStorage` для конкретного адреса сайта и профиля браузера. Люди, использующие общий профиль браузера на одном устройстве, увидят общие отметки. На другом устройстве или по другому адресу курс начнётся с отдельным прогрессом.
